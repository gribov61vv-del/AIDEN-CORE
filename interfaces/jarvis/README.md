# JARVIS V5 — локальный голосовой интерфейс

JARVIS — интерфейс голосового ввода и озвучивания, не отдельное reasoning-ядро.

## Маршрутизация
- По умолчанию распознанный запрос отправляется POST на WOV `127.0.0.1:8000/ask`, далее WOV маршрутизирует его в TRIAD.
- Команда, начинающаяся с `Пикачу `, отправляется в отдельный PIKACHU API на `127.0.0.1:8001/ask?q=...`.
- Команда `статус` проверяет WOV/TRIAD и PIKACHU.
- Простые локальные команды: приветствие, время, браузер, выход.

TRIAD остаётся основным reasoning-модулем. PIKACHU вызывается отдельно и маркируется экспериментальным. В текущей активной реализации PIKACHU обнаружена заглушка `Processing: ...`; этот ответ не является подтверждённым рассуждением.

## Зависимости
Python 3, SpeechRecognition, pyttsx3, доступный микрофон и аудиобэкенд. Распознавание речи использует Google Speech Recognition и поэтому требует интернет. Сетевой ответный маршрут к TRIAD локальный; внешний OpenAI API key не используется.

## Запуск вручную
Из корня репозитория:
`python interfaces/jarvis/jarvis.py`

Не добавлять в автозапуск, пока отдельно не проверены микрофон, разрешения Android и озвучивание.
